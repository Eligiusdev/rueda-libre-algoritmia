# Rueda Libre: algoritmia

Este repositorio documenta el diseño de un algoritmo para alquilar una bicicleta. La bitácora conserva la primera versión, las ambigüedades identificadas en su revisión y la versión corregida, además del análisis de las características de un algoritmo y los pilares del pensamiento computacional.

## Contenido

- [Bitácora del alquiler de una bicicleta](./bitacora.md): versiones del algoritmo y análisis.
- [`algoritmos/`](./algoritmos/README.md): espacio para las representaciones e implementaciones del algoritmo.
